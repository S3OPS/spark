## Architecture Highlights

### Backend (Python/FastAPI)
```
backend/
├── api/main.py           # 25+ REST endpoints
├── database/models.py    # 8 SQLAlchemy models
└── services/
    ├── signal_compression.py   # Market signal analysis
    ├── offer_generator.py      # Product creation
    ├── deployment.py           # Landing pages + payments
    ├── distribution.py         # Multi-platform posting
    └── scaling.py              # Revenue optimization
```

### Database Schema
- **Signals**: Market opportunities with scoring
- **MicroOffers**: Digital products ($10-50)
- **Analytics**: Impressions, clicks, conversions
- **Revenue**: Transaction tracking
- **DistributionPosts**: Content scheduling
- **EmailSubscribers**: Customer list
- **AutomationConfig**: System rules

### Frontend
- Responsive HTML/CSS/JS dashboard
- Real-time metrics updates
- One-click actions
- Progress visualization
- Revenue tracking

### Automation
- Signal scanning every 6 hours
- Offer generation twice daily
- Content posting every 2 hours
- Hourly reinvestment checks
- Daily performance reports

## Key Technical Decisions

### 1. **Modular Architecture**
- Each service is independent
- Easy to test and maintain
- Scalable horizontally

### 2. **AI Integration**
- OpenAI for content generation
- Fallback to templates
- Cost-effective approach

### 3. **Database Choice**
- SQLite for development
- Easy migration to PostgreSQL
- Zero setup required

### 4. **Vanilla Frontend**
- No framework dependencies
- Fast load times
- Easy to customize

### 5. **ToS Compliance**
- Platform-first approach
- Value over spam
- Rate limiting built-in
